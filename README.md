# WinTabsGo

**语言：** **中文** | [English](README_English.md)

WinTabsGo 给 Windows 桌面窗口加上浏览器式标签。把多个窗口收成一组，用标签切换、拖放和贴靠。

当前版本：**zh_2026.10.07.7**  
维护者：zhihuikeji  
系统：Windows 10、Windows 11

本仓库目前只托管可运行的发布文件。源码还在完善，暂不提供。
